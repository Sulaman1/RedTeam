# START HERE: Concise Red Team Engineering

**Main field guide:** `Red_Team_Engineering_Concise_Field_Guide.md` (also provided as PDF separately)  
**Printable cheat sheets:** `Red_Team_Engineering_14_Cheat_Sheets.md` (also provided as PDF separately)  
**Lab exercises:** `labs/` with 13 standalone Python programs, input fixtures, and a `setup.sh` script  
**Suggested order:** Modules 1-6 foundations, 7-11 operator/analyst, 12-16 advanced and capstone  
**Time:** About 12 weeks if studying consistently, longer when reviewing difficult material

All scripts are for owned, authorized, offline or loopback-only training. No source file requires root privileges. The HTTP demo's identity header is intentionally not real authentication; never deploy it publicly.

See `Lab_Quickstart.md` for run commands and expected results, and `Capstone_Report_Template.md` for a final report.

This is a **concise companion** to a larger 120-chapter book. It curates the most transferable concepts; it is not an exhaustive replacement for the specialist chapters or professional experience.
